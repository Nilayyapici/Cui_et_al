STEP 1 — Z-projection of Z/t series 

✅ Run: Step1_BatchZProjectionMaker.m

Set parameters:

ProjectionType=1;        % 1 = Max projection, 2 = Mean projection
WriteMultiPageTiff=0;    % 0 = separate .tif images, 1=combined tiff images
WriteSeparateTiff=1;     % 1 = separate .tif images, 0=combined tiff images

list_of_directories = {...
   'D:\2PhoData\230702'...
};

Output:
	•	Creates a folder named ZProjected inside each data folder
	•	Saves projected images there (one per time frame)

⸻

✅ Run: Step2_BatchRegistration.m

Set parameters:

GetFixedFrameBeforeStart=1;
ChooseFixedFrame=0;
DoAutoFixedFrame=1;
AutoFixedFrameNo=345;

RunRegistration=1;
UseChoosedFixedFrame=0;
UseAutoFixedFrame=1;
UseAdjustedFixedImgForReg=0;

xmlname='Experiment.xml';
ProjFolderName='ZProjected';
TransformType='rigid';   % try 'rigid' first; if bad try 'translation'

list_of_directories = {...
   'F:\2PhoData\240119'...
   'F:\2PhoData\240121'...
   'F:\2PhoData\240122'...
};

Output:
Saves registered images into:
	•	ZProjected\Reg_Matlab_rigid or
	•	ZProjected\Reg_Matlab_translation

Critical checkpoint (must do):
	1.	Open the registered image sequence and visually check registration quality.
	2.	If poor: Re-run Step 2, switching TransformType between rigid and translation.

If MATLAB registration still fails:
	•	Use FIJI TurboReg to register the ZProjected stack. Save output as an image sequence into: ZProjected\TurboReged
	•	If TurboReg still fails: discard the trial or manually register frames using FIJI TrakEM2.

⸻

STEP 3 — ROI fluorescence extraction (raw intensity time series)

✅ Run: Step3_BatchExtractionMultiROIVer.m

Set parameters:

xmlname='Experiment.xml';
UseMeanProjOrMaxProj='mean';  % 'mean' or 'max' t-projection summary image
ThresholdRatio=0.5;

list_of_directories = {...
   'D:\2PhoData\240119'...
   'D:\2PhoData\240121'...
   'D:\2PhoData\240122'...
};

What you do during the step:
	•	Draw: one or more ROI(s) for target area or cell bodies
	•	Draw: one background ROI

Output:
	•	Extracts mean intensity for each ROI from every frame
	•	Writes an Excel file: RegFluoDatL.xlsx
	•	Saves two copies: 1. inside the registered image folder, 2. inside a RawFluo folder
				
Each file contains time-series columns for each ROI and background.

⸻

STEP 4 — Extract optogenetic stimulation timing and add “Light ON” column

4A. Rename ThorSync folders (critical!)

Before running Step 4:
	•	Rename each ThorSync folder:
	•	from ThorSync001
	•	to ThorSync[TrialName]
The ThorSync folder name must match the trial folder name for automatic matching.

4B. Run stim extraction + preview plotting

✅ Run: Step4_BatchPlotting_MultiROI.m

Set key parameters (core ones):

BackGroundSubtractionOn1OrOff0=1; Set this to 1 if you want background subtraction, set this to 0 if you don’t want background subtraction 
RawFluoFileName='RegFluoDatL.xlsx';
xmlname='Experiment.xml';

ThorSyncFileName='Episode001.h5';
ThorSyncSettingFileName='ThorRealTimeDataSettings.xml';

BasalFrameTime=10;
BalsalFEndTime=3; %This means the basal frame is set to "from the 13 secs before first stim to 3 secs before first stim."
CutTailFrameNo=0;
LeastStimInterval=100;
BGIndThre=0.55;

AutoDetectTrialTime=1;
ImageTimeMin=8;     % 8 for 8-min trials, 4 for 4-min
ImageTimeSec=0;

PulseOn=0;
PesudoFirstStimTime=31;

list_of_directories = {...
   'D:\2PhoData\240119'...
   'D:\2PhoData\240121'...
   'D:\2PhoData\240122'...
};

Output:
	•	Quick dF/F preview plots for each trial
	•	Adds a column indicating stimulus ON/OFF frames (from ThorSync for Opto trials)

Important: These plots are only for QC preview (not used in figures).
Must manually verify stim timing by comparing ThorSync timing to the actual background elevation in the image stack (ThorSync can be offset).
