BEFORE YOU START — Data organization and required files

	1.	Confirm trial folders are properly named and organized (consistent naming is required).
	•	Example: D:\2PhoData\210518\M1T3i-4m-ZT-IN1_GCa,25F11A24D12D_Chr,St,FO,LP20G20,10mA1s,RA
	
	2.	Each trial must have:
	•	raw imaging data + Experiment.xml
	•	ingestion annotation: Ingxxxx.txt
	•	ThorSync output for optogenetics (Episode file), correctly linked to trial name (see Step 4)

****************************************************************************************************************************************************************************************************************

A. PROCESS RAW DATA

STEP 1 — Z-projection of z-stacks

✅ Run: Step1_BatchZProjectionMaker.m

Set:
ProjectionType=1;        % 1 = Max projection, 2 = Mean projection
WriteMultiPageTiff=0;    
WriteSeparateTiff=1;
list_of_directories = {...
   'D:\2PhoData\230702'...
};

Output:
	•	Creates ZProjected folder in each dataset folder.

⸻

STEP 2 — Image registration (motion correction)

✅ Run: Step2_BatchRegistration.m

Set:

GetFixedFrameBeforeStart=1;
ChooseFixedFrame=0;
DoAutoFixedFrame=1;
AutoFixedFrameNo=345;

RunRegistration=1;
UseChoosedFixedFrame=0;
UseAutoFixedFrame=1;

xmlname='Experiment.xml';
ProjFolderName='ZProjected';
TransformType='rigid';

list_of_directories = {...
   'F:\2PhoData\240119'...
   'F:\2PhoData\240121'...
   'F:\2PhoData\240122'...
};

Output:
	•	Registered images saved in:
	•	ZProjected\Reg_Matlab_rigid or ZProjected\Reg_Matlab_translation

QC required:
	•	Manually check registration quality.
	•	If poor, rerun using the other TransformType.
	•	If still poor, use FIJI TurboReg → save into ZProjected\TurboReged.

⸻

STEP 3 — Extract raw fluorescence time series from ROIs

✅ Run: Step3_BatchExtractionMultiROIVer.m

Set:

xmlname='Experiment.xml';
UseMeanProjOrMaxProj='mean';
ThresholdRatio=0.5;

list_of_directories = {...
   'D:\2PhoData\240119'...
   'D:\2PhoData\240121'...
   'D:\2PhoData\240122'...
};

During step:
	•	Draw ROI(s) + background ROI on the summary image.

Output:
	•	Writes RegFluoDatL.xlsx
	•	Saves copies in:
	•	registered image folder and
	•	RawFluo folder

⸻

STEP 4 — Extract optogenetic stimulation timing and add “Light ON” column

4A. Rename ThorSync folders (critical!)

Before running Step 4:
	•	Rename each ThorSync folder:
	•	from ThorSync001
	•	to ThorSync[TrialName]
The ThorSync folder name must match the trial folder name for automatic matching.

4B. Run stim extraction + preview plotting

✅ Run: Step4_BatchPlotting_MultiROI.m

Core settings:

BackGroundSubtractionOn1OrOff0=1;
RawFluoFileName='RegFluoDatL.xlsx';
xmlname='Experiment.xml';

ThorSyncFileName='Episode001.h5';
ThorSyncSettingFileName='ThorRealTimeDataSettings.xml';

AutoDetectTrialTime=1;
ImageTimeMin=4;   % use 4 for 4-min trials, 8 for 8-min
ImageTimeSec=0;

BasalFrameTime=10;
BalsalFEndTime=3;
LeastStimInterval=100;
BGIndThre=0.55;

list_of_directories = {...
   'D:\2PhoData\240119'...
   'D:\2PhoData\240121'...
   'D:\2PhoData\240122'...
};

Output:
	•	Quick dF/F preview (QC only; not used in final figures)
	•	Adds extracted opto stim ON/OFF timing (from ThorSync)

QC required:
	•	Manually verify stim ON/OFF frames by comparing to the frame where background elevation appears in the image stack (ThorSync can be offset).

⸻

B. OPT0 + INGESTION dF/F0 PROCESSING (figure-ready outputs)

Inputs required for each trial (Folder A)

Create one analysis folder (“Folder A”) and place BOTH:
	•	RegFluoDatL-xxxx.xlsx (from Step 4 outputs)
	•	matching ingestion file Ingxxxx.txt
✅ Trial names must match across files.

⸻

STEP 5 — Add ingestion indicator (and keep Light ON indicator)

✅ Run: Step5_Add_Ingestion_Bout_Indicator_OptoWithIng.m
(location: ...\IngestionImaging\ForOptoIng)

Use these settings (Fig. 4i and Fig. 6b–e are 4-min trials):

ImageTimeMin=4;
ImageTimeSec=0;
TotalTimeSec=ImageTimeMin*60+ImageTimeSec;

WriteInAnotherCol=1;  
% MUST be 1: keeps both ingestion indicator and light-on indicator

Output:
	•	Creates folder: IngAdded
	•	Generates files containing BOTH:
	•	ingestion bout indicator
	•	optogenetic “Light ON” indicator
