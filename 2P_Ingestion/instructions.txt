BEFORE YOU START — Data organization
	1.	Make sure each trial is in a clearly named folder (consistent naming is critical).
	•	Example trial folder: D:\2PhoData\210518\M1T3i-4m-ZT-IN1_GCa,25F11A24D12D_Chr,St,FO,LP20G20,10mA1s,RA

	2.	Confirm each trial folder includes:
	•	raw imaging data (ThorImage output)
	•	Experiment.xml (ThorImage metadata)

********************************************************************************************************************************************************************************************************
A. Processing raw imaging data

STEP 1 — Z-projection of Z/t series 

✅ Run: Step1_BatchZProjectionMaker.m

Set parameters:

ProjectionType=1;        % 1 = Max projection, 2 = Mean projection
WriteMultiPageTiff=0;    % 0 = separate .tif images, 1=combined tiff images
WriteSeparateTiff=1;     % 1 = separate .tif images, 0=combined tiff images

list_of_directories = {...
   'D:\2PhoData\230702'...
};

Output:
	•	Creates a folder named ZProjected inside each data folder
	•	Saves projected images there (one per time frame)

⸻

STEP 2 — Image registration (motion correction)

✅ Run: Step2_BatchRegistration.m

Set parameters:

GetFixedFrameBeforeStart=1;
ChooseFixedFrame=0;
DoAutoFixedFrame=1;
AutoFixedFrameNo=345;

RunRegistration=1;
UseChoosedFixedFrame=0;
UseAutoFixedFrame=1;
UseAdjustedFixedImgForReg=0;

xmlname='Experiment.xml';
ProjFolderName='ZProjected';
TransformType='rigid';   % try 'rigid' first; if bad try 'translation'

list_of_directories = {...
   'F:\2PhoData\240119'...
   'F:\2PhoData\240121'...
   'F:\2PhoData\240122'...
};

Output:
Saves registered images into:
	•	ZProjected\Reg_Matlab_rigid or
	•	ZProjected\Reg_Matlab_translation

Critical checkpoint (must do):
	1.	Open the registered image sequence and visually check registration quality.
	2.	If poor: Re-run Step 2, switching TransformType between rigid and translation.

If MATLAB registration still fails:
	•	Use FIJI TurboReg to register the ZProjected stack. Save output as an image sequence into: ZProjected\TurboReged
	•	If TurboReg still fails: discard the trial or manually register frames using FIJI TrakEM2.

⸻

STEP 3 — ROI fluorescence extraction (raw intensity time series)

✅ Run: Step3_BatchExtractionMultiROIVer.m

Set parameters:

xmlname='Experiment.xml';
UseMeanProjOrMaxProj='mean';  % 'mean' or 'max' t-projection summary image
ThresholdRatio=0.5;

list_of_directories = {...
   'D:\2PhoData\240119'...
   'D:\2PhoData\240121'...
   'D:\2PhoData\240122'...
};

What you do during the step:
	•	Draw: one or more ROI(s) for target area or cell bodies
	•	Draw: one background ROI

Output:
	•	Extracts mean intensity for each ROI from every frame
	•	Writes an Excel file: RegFluoDatL.xlsx
	•	Saves two copies: 1. inside the registered image folder, 2. inside a RawFluo folder
				
Each file contains time-series columns for each ROI and background.

⸻

STEP 4 — This step is not used for Ingestion Only trials-SKIP.

B. dF/F0 analysis aligned to ingestion (figures)

For each trial, you need:
	•	RegFluoDatL-xxxx.xlsx (or RegFluoDatL.xlsx)
	•	A matching ingestion annotation file: Ingxxxx.txt

STEP 5 — Add ingestion bout indicator

✅ Run: Step5_Add_Ingestion_Bout_Indicator_Ing.m

Set:

ImageTimeMin=8;
ImageTimeSec=0;

Output:
	•	Creates an IngAdded folder containing files with the ingestion bout indicator added.

⸻

STEP 6 — Segment and calculate dF/F aligned to ingestion onset

✅ Run: Step6_Segmentation_df_f_calculation_Ing.m

Standard settings used for ingestion plots:

	BackGroundSubtractionOn1OrOff0=0;
	Time0IsStimOnIndicator1OrIngestionOnIndicator2=2;
	TimeStartBeforeStim=30;
	TimeStopAfterStim=30;
	TimeResolution=1;
	dFFOutlierThreshold=10000;
	ImageTimeMin=8;
	ImageTimeSec=0;
	TotalTimeInSec=ImageTimeMin*60+ImageTimeSec;
	BasalFTimeLength=10;
	BalsalFEndTime=0; % basal window = -10s to 0s before ingestion onset

Output:
	•	Creates IngAdded\BindFFSeg (and sometimes IntdFFSeg)
	•	Contains ingestion-aligned dF/F data tables for each trial/ROI

Special note for some pipelines (fluorescent food ingestion stats):
	•	Rename folder:
	•	BindFFSeg → BindFFSegIo
(Do this when the downstream plotting/stat script expects BindFFSegIo.)

D. Data analysis for fluorescent food ingestion 

(Fig. 4f; Ext. Data Fig. 10 c,f,h,j,l)

STEP 8d — Calculate peak dF/F0 and “persistence” (peak width at half max)

✅ Run: Step8d_Calculate_Persistency_FluoFoodIng.m

What it computes:
	•	Peak dF/F0 during ingestion bout
	•	Peak width (“persistence”): time between rising above and falling below 0.5 × peak

ROI mapping:
	•	ROI1 = Esophagus
	•	ROI2 = Crop duct

Which metrics were used:
	•	Ext. Data 10c, 10j: use peak width of ROI2
	•	Ext. Data 10f, 10l: use peak width of ROI1
	•	Fig. 4f: use peak dF/F0 of ROI2
	•	Ext. Data 10h: use peak dF/F0 of ROI1
